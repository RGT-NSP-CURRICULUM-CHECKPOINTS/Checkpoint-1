# Node.js File System Checkpoint

## 📌 Overview
This project is a simple **Node.js script** that demonstrates how to read from and write to files using Node.js’s built-in **`fs` (File System) module**.  
It was built as part of a backend development checkpoint to understand basic Node.js file operations.

---

## 🎯 Objectives
- Understand how Node.js interacts with the file system
- Read data from a file
- Write data to a file
- Handle basic errors during file operations
- Run a Node.js script from the command line

---

## 🛠️ Technologies Used
- **Node.js**
- **fs module (built-in)**

---

## 📂 Project Structure

```
project-folder/
```
