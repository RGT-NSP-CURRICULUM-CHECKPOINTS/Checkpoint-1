 <h1> 📁 Node.js File System Checkpoint</h1>
 <br>
 <h2> 📌 Overview </h2>

<p><b>This project is a simple Node.js script that demonstrates how to read from and write to files using the built-in fs (File System) module.
It was built as part of a backend development checkpoint to understand basic Node.js file operations.</b></p>
<br>

   <h3> 🎯 Objectives <h3>
<ul>
<li>Understand how Node.js interacts with the file system </li>

<li>Read data from a file</li>

<li>Write data to a file</li>

<li>Handle basic errors during file operations</li>

<li>Run a Node.js script from the command line</li>
</ul>
